================================================================================
KEY TECHNICAL DECISIONS / GOTCHAS
================================================================================
- The editorial "sports-almanac" REDESIGN (DM Serif Display, gold-restrained
  palette, tabular nums, sharper cards) is intentionally KEPT SEPARATE from
  production. It lives on feature/visual-redesign (PR #35, base redesign-base)
  and is also bundled inside #33. The user reverted Manrope→DM Serif, then chose
  to ship ONLY mobile responsiveness to prod, leaving the redesign for review.
- Shared mobile layer = assets/mobile.css, linked LAST in <head> so its
  @media(max-width:768px) rules override the pages' inline base rules by source
  order. Drawer JS = assets/mobile.js. Breakpoint is 768px.
- THE recurring fix: `.main{min-width:0}` on flex layouts — lets the flex item
  shrink below content width so wide tables/topbars don't force page overflow.
- Rankings wide table → mobile CARDS: CSS-only, scoped to #rankingsTable, thead
  hidden, each <tr> becomes a flex card; stat labels come from data-label added
  to each stat <td> from p.statLabels (formatStat calls unchanged → desktop
  byte-identical). In ALL view the inline label is hidden to avoid doubling.
- Stripe crash root cause: billing.js built `new Stripe('')` at module top level;
  any importer (incl. api/sports.js via auth.js) crashed when the key was absent
  (Preview env). Fixed with a lazy Proxy that defers construction to first use.
  STRIPE_SECRET_KEY is Production-scoped only (not Preview) — that's why previews
  showed "Couldn't load this slate"; production was always fine.
- The dashboard "Last Night's Results" games and the OLD home ticker items were
  HARDCODED sample data. The app has NO unified cross-sport live game-status API;
  only PGA inField + NFL/CFB pickem game states exist, plus per-player recent-form
  `tag`+`formReason` in /api/sports?sport=X (hot/cold).
- PR #40 (data-driven ticker) used the recent-form proxy: show a sport only if it
  has current hot/in-form players, hide the ticker when none. It WORKS (verified
  against real MLB data pulled from prod), but the user chose to REMOVE the ticker
  entirely instead (#41) and closed #40 (left open branch feature/ticker-live-events).
- Vercel Deployment Protection (ssoProtection) was toggled off for iPhone testing
  then re-enabled to "prod_deployment_urls_and_all_previews" (= previews gated,
  production custom domain public). It is currently ON.
